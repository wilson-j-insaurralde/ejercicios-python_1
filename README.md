# 🐍 Python Mastery: Core Engineering & Backend Fundamentals

Este repositorio es el resultado de un entrenamiento intensivo de **108 módulos teóricos** y la resolución de **más de 300 ejercicios prácticos**. El objetivo principal es construir una base técnica inquebrantable en Python, orientada a la resolución de problemas complejos y la creación de software escalable.

---

## 🚀 Estructura del Entrenamiento

### 📦 Nivel 1: Lógica y Algoritmos (Fundamentos)
* **Control de Flujo:** Estructuras secuenciales, condicionales simples/anidadas y ciclos repetitivos (`while`, `for`).
* **Estructuras de Datos:** Manejo avanzado de Listas (paralelas, anidadas, ordenamiento), Tuplas, Diccionarios y Sets (conjuntos).
* **Modularización:** Programación estructurada, funciones con parámetros mutables/inmutables y retorno de datos.

### 🏛️ Nivel 2: Programación Orientada a Objetos (POO)
* **Arquitectura de Software:** Declaración de clases, herencia, colaboración entre objetos y métodos especiales (`__init__`, `__str__`).
* **Ingeniería de Clases:** Variables de clase, redefinición de operadores matemáticos/relacionales y metadatos.
* **Decoradores Avanzados:** Implementación de `@property`, `functools.wraps`, decoradores con argumentos y encadenamiento de decoradores.

### 🎨 Nivel 3: Desarrollo de Interfaces Gráficas (GUI)
* **Framework Tkinter & ttk:** Gestión de layouts, captura de eventos de mouse y diseño de interfaces profesionales.
* **Componentes Complejos:** Uso de Canvas (gráficos y movimiento), Notebook, ScrolledText y manejo de ventanas de diálogo.
* **Proyectos Visuales:** Integración de archivos de texto con interfaces visuales para lectura y escritura de datos.

### 🗄️ Nivel 4: Persistencia y Gestión de Datos (SQL)
* **Motores de Bases de Datos:** Implementación de ciclos **CRUD** (Altas, Bajas, Modificaciones) conectando Python con:
    * **PostgreSQL** (psycopg2)
    * **MySQL** (mysql-connector)
    * **SQLite** (Bases de datos embebidas)
* **Intercambio de Datos:** Procesamiento de archivos **JSON**, serialización, deserialización y acceso a Internet mediante `urllib`.

### ⚡ Nivel 5: Programación Avanzada y Funcional
* **Optimización de Código:** List Comprehension, Funciones Lambda y Funciones de Orden Superior.
* **Lógica Compleja:** Aplicación de **Recursividad** (Ejemplo: lógica de Buscaminas), Closures (Clausuras) y manejo de excepciones robusto (`try/except/finally`).
